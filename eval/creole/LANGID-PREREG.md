# Creole language-ID tier — PRE-REGISTRATION (written 2026-10-13, before the tier was run on any held-out sentence)

Baseline being improved: `eval/creole/BASELINE.md` §1 (tip 59d8264): of 1,134 held-out creole sentences 180 right (16%),
465 confidently an unrelated language (41%), 183 as-base, 30 sibling, 276 abstain. The harm is the confident-wrong.

## What is built

A tier ABOVE the base detector (`fold-chat-langid.js` is not re-tuned; its core and UDHR tiers are untouched):

1. `fold-chat-creole-priors.js` (generated by `scripts/build-creole-priors.mjs`): a word + character-1-3-gram prior per
   creole/pidgin in the SAME format and the SAME builder functions as the base priors (KW/K2/K3/FW/RHO/ALPHA unchanged),
   plus a metadata table (code, lexifier-family) and the two derived cutoff tables below.
2. `fold-chat-langid-creole.js`: `creoleTier(...)`. For a Latin-script text it scores the creole priors TOGETHER WITH the
   base core Latin priors in one scoring group (so the feature accounting is the one the base uses and a feature only a
   creole lists costs the core languages their floor), and reads only the statistic
   `T_c = s_c − max over core languages s_i` (nats). It never alters the base verdict computation: it runs after it.
3. `identify()` consults the tier after `core` is computed. The tier either returns nothing (the output is then exactly
   today's — no new field, no reordering) or it owns the answer: a specific creole, a lexifier-family label, or `unknown`.

## Data (BUILD FROM only)

* UDHR translations: hat_kreyol, hat_popular, 052 (Morisyen), crs, 056 (Saint Lucian), 055 (Jamaican), pcm, tpi, pap, sag,
  kea, pov/008, kri, bis, pis, lin — split by line.
* Kreyol-MT OPUS bitexts, creole side: djk, hat, gcf, tpi, crs — split by the pair's id column.
* APiCS survey chapters: creole words of each numbered interlinear example (`(N)` then word/gloss alternating lines).
* `janus/priors/pos-{pcm,hat,pap,kea,bis,pis,crs,pov,lin}.json`: forms with counts (vocabulary; a form has no sentence id so
  it is used whole; its UD train split is what the user named).
* NEVER read: every file in BASELINE.md "HELD-OUT FILES". `scripts/build-creole-priors.mjs` refuses those paths.
* Split: `fold = FNV-1a(source + ":" + id) mod 5`. Priors shipped are built from ALL five folds; the cutoffs that need an
  out-of-sample creole score (the within-family margin) are computed from 5-fold cross-validation (a sentence scored only by
  priors built from the other four folds). The held-out CreoleVal files are the test set; nothing in them is in any fold.

## Cutoffs — derived, none hand-set

* `τ_c` (is it creole c at all?): the maximum of `T_c` over the NULL, a pool of non-creole Latin-script sentences that
  includes the lexifiers' own text: the 40-language `eval/langid/labelled.json` asks, the UDHR sentences of the 40 core
  languages and of every non-creole UDHR language, Wikipedia/classics sentences, the lexifier columns of the Kreyol-MT
  bitexts and of the Tatoeba files that are NOT in the held-out list; each also under the declared perturbations below.
  A text fires c only if `T_c > τ_c`. With k null sentences the rule-of-three upper bound on the false-fire rate is 3/k.
* `μ_{a,b}` (which creole of a family?): the largest lead of a wrong-best creole among cross-validated sentences of a and b.
  A specific name needs lead `> μ`; otherwise the tier returns the lexifier family (`cpf` French-, `cpe` English-,
  `cpp` Portuguese-, `cpd` Dutch-based creole; ISO 639-2 collective codes), and if the two best are of different
  families, `unknown`.
* No minimum token count, no margin, no weight is typed in. (Base DECLARED constants are inherited, unchanged.)
* Declared perturbations (a mechanical transform, not a threshold): diacritics stripped; one adjacent transposition in
  every 3rd token; leetspeak digits for letters (`3 4 0 1 5 7 for e a o i s t`) in every 2nd token of length ≥ 3.
  Leetspeak is read by the tier as a second reading of a token that mixes letters and digits (as fold-chat-typing.js does).

## Claims and what falsifies each

* **U1 UNCHANGED.** For every text that is not creole the full `identify()` object is byte-identical to the pre-change
  commit: (a) `labelled.json` all three splits; (b) ≥ 1,000 sentences sampled by hash from the UDHR files of the 40 core
  languages (not the tests); (c) the non-creole UDHR languages; (d) all of (a)–(c) perturbed. FALSIFIED by any difference.
* **U2 SUITES.** `fold-chat-langid*.test.mjs`, `fold-chat-lang*.test.mjs`, `eval/langid` core suites: same pass/fail by name.
* **C1 TARGET.** On `node eval/creole/id-heldout.mjs` (the same sentences): total `other-wrong` falls, and `right` does not
  fall in total or in any language. FALSIFIED if either fails; N is shown per language.
* **C2 NOT A GUESS.** The tier's own confident-wrong rate on held-out creole (a specific creole other than the true one,
  or a creole family of the wrong lexifier) is reported; the claim is that it is below the base's 41%.
* **C3 PAIRS.** Haitian/Guadeloupean/Saint Lucian, Nigerian Pidgin/English, Seselwa/Morisyen: report, per pair, how often
  the tier names the right one, the family, or abstains. The claim is that it never names the wrong specific language
  above `μ`; this is checked on the CV sentences AND on the held-out ones.
* **C4 TYPING.** Under the declared perturbations, the creole val sentences the tier names correctly keep their name at a
  rate reported with N; the null under the same perturbations yields zero fires (this is U1(d)).
* **C5 LIVE.** `drive.mjs --prompts eval/creole/prompts.json --only creole --conc 1` against this worktree: the believed
  language and the Wikipedia editions contacted are reported, not scored.

## Predictions, written before the run (so a miss is visible)

Other-wrong falls by more than half (465 → < 230). `right` rises for Haitian, Tok Pisin, Papiamentu, Sango and Mauritian and
is flat for Nigerian Pidgin (its sentences are English orthography; as-base stays). Jamaican and Guadeloupean stay mostly
abstain/family: there is very little build text for them (UDHR 055 only; gcf is Bible-style). UNCHANGED holds 100%.
Known threats named now: the held-out Tatoeba/MT domain differs from UDHR/Bible/treebank text, so recall will be lower
than CV; Nigerian Pidgin held-out sentences come from the same NSC corpus as the `pos-pcm` train split, so its gain is
in-domain and optimistic; `lin` is a Bantu lingua franca, not a creole — kept only because the baseline listed it.
